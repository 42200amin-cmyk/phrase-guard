# Phrase Guard

ابزار **رمزنگاری محلی** برای متن و فایل — کاملاً سمت مرورگر، بدون سرور.

**نسخه وب:** [https://42200amin-cmyk.github.io/phrase-guard/](https://42200amin-cmyk.github.io/phrase-guard/)

---

## قابلیت‌ها

- ساخت کلید BIP-39 (۱۲ / ۲۴ کلمه) یا رمز دلخواه
- رمزنگاری و رمزگشایی متن (`pg2:` و سازگاری با `pg1:`)
- رمزنگاری فایل و تصویر تا حدود ۲۵ مگابایت (قالب `.pgf` / `pgf1:`)
- رابط چت‌مانند برای موبایل و دسکتاپ
- پردازش فقط در مرورگر — کلید و محتوا به هیچ سروری ارسال نمی‌شود

## امنیت

| مورد | جزئیات |
|------|--------|
| الگوریتم | AES-256-GCM |
| مشتق‌سازی کلید | PBKDF2-HMAC-SHA256 ، ۲۵۰٬۰۰۰ دور |
| نمک | تصادفی ۱۶ بایت برای `pg2:` / `pgf1:` |
| IV | ۱۲ بایت تصادفی |
| ساخت کلید | `crypto.getRandomValues` مرورگر |

کلید را فقط از کانال امن به اشتراک بگذارید. هر کسی که کلید را داشته باشد می‌تواند پیام‌ها و فایل‌ها را بخواند.

## فرمت‌ها

- **متن جدید:** `pg2:` + Base64(salt ۱۶ + IV ۱۲ + ciphertext)
- **متن قدیمی:** `pg1:` یا Base64 بدون پیشوند (نمک ثابت میراثی)
- **فایل:** `pgf1:` + Base64(...) ؛ متن اصلی = JSON متادیتا + خط جدید + بایت‌های فایل

## ربات تلگرام (اختیاری)

نسخهٔ جداگانه‌ای به‌صورت ربات تلگرام هم وجود دارد که همان فرمت‌ها را پشتیبانی می‌کند.  
توجه: در ربات، کلید روی سرور ذخیره می‌شود تا پردازش ممکن باشد — برای داده‌های خیلی حساس فقط از **همین نسخهٔ وب** استفاده کنید.

## اجرا به‌صورت محلی

فایل `index.html` را در مرورگر باز کنید. نیازی به نصب یا سرور نیست.
